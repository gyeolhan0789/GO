### 1.4 로컬 실행

Backend:

```bash
cd backend
docker compose -f docker-compose.local.yml up -d
./gradlew clean test
./gradlew bootRun --args='--spring.profiles.active=local'
```

Windows PowerShell:

```powershell
cd backend
docker compose -f docker-compose.local.yml up -d
.\gradlew.bat clean test
.\gradlew.bat bootRun --args='--spring.profiles.active=local'
```

로컬 접속 정보:

| 항목 | 값 |
| --- | --- |
| Backend API | `http://localhost:8080` |
| Swagger UI | `http://localhost:8080/swagger-ui/index.html` |
| MySQL | `localhost:3306/wecandoit` |
| Redis | `localhost:6379` |

Frontend Mobile:

```bash
cd frontend
nvm use
npm ci
cp .env.example .env
npm run start:dev
npm run android:dev
```

Admin UI:

```bash
cd frontend/admin
npm ci
VITE_API_ENV=dev VITE_API_BASE_URL=https://i15a506.p.ssafy.io/dev npm run build
```

AI Server:

```bash
cd ai/ai-server
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

## 3. DB 덤프 파일 최신본

포팅용 DB 덤프 파일 위치:

```text
exec/db/latest-wecandoit-dump.sql
```

덤프 기준:

- Flyway migration `V1`부터 `V7`까지 적용한 최신 schema.
- `backend/src/main/resources/db/local/data.sql`의 local seed data 포함.

운영 DB dump 생성:

```bash
mkdir -p exec/db
docker exec wecandoit-mysql-prod \
  mysqldump -uroot -p"$DB_ROOT_PASSWORD" \
  --databases wecandoit \
  --single-transaction \
  --routines \
  --triggers \
  --events \
  --default-character-set=utf8mb4 \
  > exec/db/latest-wecandoit-dump.sql
```

dev DB dump 생성:

```bash
mkdir -p exec/db
docker exec wecandoit-mysql-dev \
  mysqldump -uroot -p"$DB_ROOT_PASSWORD" \
  --databases wecandoit \
  --single-transaction \
  --routines \
  --triggers \
  --events \
  --default-character-set=utf8mb4 \
  > exec/db/latest-wecandoit-dev-dump.sql
```

dump 복구:

```bash
docker exec -i wecandoit-mysql-prod \
  mysql -uroot -p"$DB_ROOT_PASSWORD" < exec/db/latest-wecandoit-dump.sql
```
