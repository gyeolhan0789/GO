## 기대

**기대**는 걸음/미션 인증을 기반으로 하는 빙고 게임 서비스입니다.

사용자는 일상 속 걸음이나 활동 미션을 수행하고, 그 결과를 사진으로 인증합니다.
인증된 미션은 AI가 자동으로 판정하여 빙고판의 칸을 채우는 데 사용되며,
가로/세로/대각선을 완성하면 빙고를 달성하는 방식으로 게임이 진행됩니다.

빙고를 통해 얻은 성과는 포인트와 아이템으로 이어지고, 이를 활용해 아바타를
꾸미거나 친구와 함께 랭킹을 겨루며 지속적인 동기부여를 얻을 수 있습니다.

### 핵심 경험

- **미션 수행**: 걷기 등 일상 활동을 미션으로 제시
- **AI 인증**: 사진 기반으로 미션 수행 여부를 자동 판정
- **빙고 게임**: 인증된 미션으로 빙고판을 채우고 완성
- **아바타 & 소셜**: 포인트/아이템으로 아바타를 꾸미고 친구와 랭킹 경쟁
