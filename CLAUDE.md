# Project Agent Rules

These rules apply when creating, reviewing, or modifying code in this repository.

## General

- Follow the conventions that match the area being changed.
- Do not introduce unspecified technologies without asking first.
- Keep changes aligned with the existing project structure and coding style.
- Remove magic strings, unused imports, unused code, and unnecessary paths.
- Run build/test after changes when the project provides a build command.

## Backend

When working on Java Spring Boot backend code, follow:

- [Java Convention](backend/docs/convention/java-convention.md)
- [Spring Boot Convention](backend/docs/convention/spring-boot-convention.md)
- [JPA Convention](backend/docs/convention/jpa-convention.md)
- [Git Convention](backend/docs/convention/git-convention.md)
- [Backend Test Convention](backend/docs/convention/back-test-convention.md)

## Frontend

When working on the React Native frontend code, follow [frontend/AGENTS.md](frontend/AGENTS.md).
